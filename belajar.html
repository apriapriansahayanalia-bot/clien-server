01 HTML Struktur halaman web ↓

Pemahaman HTML

HTML adalah bahasa markup yang digunakan untuk menyusun isi halaman web, seperti judul, paragraf, gambar, tautan, dan tombol.

  • <h1> sampai <h6> untuk judul
  • <p> untuk paragraf
  • <a> untuk tautan

Contoh struktur HTML

<!DOCTYPE html>
<html lang="id">
  <head>
    <title>Belajar HTML</title>
  </head>
  <body>
    <h1>Halo Dunia</h1>
    <p>Ini adalah paragraf pertama saya.</p>
  </body>
</html>
02 CSS Tampilan dan tata letak ↓

Pemahaman CSS

CSS digunakan untuk mengatur tampilan HTML, seperti warna, ukuran teks, jarak, garis, dan tata letak halaman.

  • color untuk warna teks
  • margin dan padding untuk jarak
  • display, grid, dan flex untuk tata letak

Contoh CSS sederhana

body {
  font-family: Arial, sans-serif;
  background-color: #f5f5f5;
  color: #222;
}

h1 {
  color: #d56b43;
  text-align: center;
}
03 Latihan Praktik membuat halaman ↓

Latihan pertama

Buat halaman profil sederhana yang berisi nama, deskripsi singkat, dan satu tombol.

  1. Buat struktur HTML dengan judul dan paragraf.
  2. Tambahkan class pada tombol dan kartu profil.
  3. Gunakan CSS untuk mengatur warna, jarak, dan ukuran teks.
